## Install

**Requires [Bun](https://bun.sh) ≥ 1.0**

```bash
npm install -g @openwork/cli
```

Or with Bun directly:

```bash
bun add -g @openwork/cli
```

Verify:

```bash
ok-cli --version
```

## Setup

### Option A — Your own API key (BYOK)

Create a `.env` in your project (or home directory):

```bash
# Anthropic (default)
echo 'ANTHROPIC_API_KEY=sk-ant-...' >> ~/.env

# OpenAI
echo 'OPENAI_API_KEY=sk-...' >> ~/.env

# Google
echo 'GOOGLE_API_KEY=AIza...' >> ~/.env
```

### Option B — OpenRouter (one key for every model)

[OpenRouter](https://openrouter.ai) lets you access hundreds of models with a single key.

```bash
echo 'OPENROUTER_API_KEY=sk-or-...' >> ~/.env
```

Then use any model slug:

```bash
ok-cli --provider openrouter --model anthropic/claude-sonnet-4-6 "..."
ok-cli --provider openrouter --model openai/gpt-4o "..."
ok-cli --provider openrouter --model google/gemini-2.0-flash "..."
ok-cli --provider openrouter --model meta-llama/llama-3.3-70b-instruct "..."
```

### Option C — OpenWork Cloud _(coming soon)_

No API keys to manage. Sign in once, all models included.

```bash
ok-cli login          # opens browser → paste token
ok-cli whoami         # verify login
ok-cli --provider openwork "explain this codebase"
ok-cli logout         # clear credentials
```

## Usage

```bash
# Interactive mode (REPL)
ok-cli

# One-shot task
ok-cli "explain this codebase"
ok-cli "fix the failing tests in src/"
ok-cli "refactor auth.ts to use async/await"

# Different model
ok-cli --model claude-opus-4-7 "review this PR"

# OpenRouter (one key, all models)
ok-cli --provider openrouter --model anthropic/claude-sonnet-4-6 "add docstrings"

# OpenWork Cloud (after `ok-cli login`)
ok-cli --provider openwork "fix the bug in main.ts"
```

### REPL commands

| Command | Action |
|---------|--------|
| `/exit` | Quit |
| `/clear` | Reset conversation context |
| `/tools` | List available tools |
| `/help` | Show commands |

## Tools

ok-cli ships with 5 built-in tools the agent can use:

| Tool | Description |
|------|-------------|
| `bash` | Execute shell commands (git, npm, tests, etc.) |
| `read_file` | Read source files |
| `write_file` | Write/overwrite files |
| `list_dir` | List directory contents |
| `search` | Grep / ripgrep pattern search |

## Configuration

| Variable | Description | Default |
|----------|-------------|---------|
| `ANTHROPIC_API_KEY` | Anthropic API key | — |
| `OPENAI_API_KEY` | OpenAI API key | — |
| `GOOGLE_API_KEY` | Google AI key | — |
| `OPENROUTER_API_KEY` | OpenRouter key (all models) | — |
| `OPENWORK_MODEL` | Override default model | `claude-sonnet-4-6` |

## Supported Providers & Models

| Provider | Flag | Key | Models |
|----------|------|-----|--------|
| Anthropic | `--provider anthropic` | `ANTHROPIC_API_KEY` | claude-sonnet-4-6, claude-opus-4-7, … |
| OpenAI | `--provider openai` | `OPENAI_API_KEY` | gpt-4o, gpt-4o-mini, … |
| Google | `--provider google` | `GOOGLE_API_KEY` | gemini-2.0-flash, gemini-1.5-pro, … |
| OpenRouter | `--provider openrouter` | `OPENROUTER_API_KEY` | any model slug from openrouter.ai |
| OpenWork | `--provider openwork` | `ok-cli login` | all models, no key needed |

```bash
# Examples
ok-cli --provider anthropic --model claude-sonnet-4-6 "..."   # default
ok-cli --provider anthropic --model claude-opus-4-7 "..."
ok-cli --provider openai --model gpt-4o "..."
ok-cli --provider google --model gemini-2.0-flash "..."
ok-cli --provider openrouter --model anthropic/claude-sonnet-4-6 "..."
ok-cli --provider openrouter --model deepseek/deepseek-r1 "..."
```

## Development

```bash
git clone https://github.com/OpenWorkai/ok-cli
cd ok-cli
bun install

# Run from source
bun run dev

# Build distributable
bun run build

# Type-check
bun run typecheck
```
